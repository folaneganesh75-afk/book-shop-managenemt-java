# Java Book Shop Management
React.js + Spring Boot + MySQL 3-tier application.
Run locally: `docker compose up -d --build`
Frontend: http://localhost:3000
Backend: http://localhost:8080/api/books
Docker images: ganeshfolane75/bookshop-backend and ganeshfolane75/bookshop-frontend
Deployment tools: Docker, Jenkins, Docker Hub, Kubernetes and Helm.
